## Project Structure

- **Core** — Domain models, controllers, DAO classes, services, validation and CSV persistence.
- **ConsoleClient** — Console-based user interface.
- **WpfClient** — WPF graphical user interface under development.

## Getting Started

1. Clone the repository.
2. Open the solution in Visual Studio.
3. Set ConsoleClient as the startup project.
4. Build and run the application.
